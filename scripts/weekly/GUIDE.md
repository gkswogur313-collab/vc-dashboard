# JH Weekly Report — 작성 가이드

매주 월요일 Claude 예약 작업이 지난주(월~일, KST) 리포트를 만든다. 독자는 VC 심사역(사용자 본인)이다.
리포트는 네 부분으로 되어 있다. **②③은 스크립트가 계산해 넣고, Claude는 ①④와 '한눈에'만 쓴다.**

| 구역 | 내용 | 누가 |
|---|---|---|
| 한눈에 | 네 구역을 가로지르는 이번 주 핵심 3~5줄 | Claude |
| ① 업계 뉴스 레이더 | vc-news 스킬 방식의 주간 시그널(Top Signals + 5대 카테고리 + 주간 인사이트) | Claude |
| ② 산업 트래킹 | 같은 주 '주간 브리핑' 원본 전체(요약하지 않음 — 화면·워드가 public/data/briefs/<id>.json 을 그대로 넣는다) | 스크립트 |
| ③ IPO 전주·금주 | 전주(대상 주)와 금주(발행 주) 심사청구·심사승인·수요예측·상장 종목(스팩 제외)과 단계별 보고서 한줄. 금주는 공시된 일정(예정) 기준, 행마다 `주: 전주/금주` | 스크립트 |
| ④ 신규 펀딩 | 그 주 펀딩 목록·합계(스크립트) + **주목 딜 5~10건 뉴스 기반 요약**(Claude) | 둘 다 |

## 절차

1. `node scripts/weekly/collect.mjs` → `tmp/weekly-base.json` (특정 주는 주 시작일 인자)
2. **① 레이더:** `vc-news` 스킬(Skill 도구로 불러온다)의 하드 룰·절차·분량 상한을 그대로 따른다. 대상 기간은 base의 `기간`. WebSearch로 카테고리별로 따로 검색하고, 원문은 WebFetch로 읽는다(구글 뉴스 중계 링크는 열리지 않으니 언론사 원문 주소를 쓴다).
   - 산업 트래킹·IPO·펀딩 구역에 이미 있는 내용을 레이더에 똑같이 반복하지 않는다. 레이더는 그 밖의 정책·회수·인력 시그널과, 그 구역들의 사건이 갖는 '함의' 위주로 쓴다.
3. **④ 주목 딜:** base `펀딩.목록`에서 5~10건을 고른다. 기준: 공개 금액이 큰 딜, 후속 라운드(시리즈B 이상), 산업·기술 기업(반도체·AI·로봇·에너지·소재·우주국방 우선, 바이오는 그다음, 금융·플랫폼·소비재는 후순위). 딜마다 WebSearch로 투자 기사를 찾아 2~4개 항목으로 쓴다: 무엇을 하는 회사인지 / 이번 라운드 규모·투자사 / 누적 투자·밸류(보도된 경우만) / 자금 사용처.
4. **한눈에:** 네 구역을 묶어 3~5줄.
5. `public/data/weekly/<주 시작일>.json` 을 아래 형식으로 쓴 뒤 `node scripts/weekly/validate.mjs public/data/weekly/<id>.json` → 통과하면 ②③과 펀딩 목록을 최신 계산값으로 다시 채우고 index.json을 갱신한다.
6. `node scripts/weekly/build-docx.mjs public/data/weekly/<id>.json` → `public/briefs/weekly/<id>.docx`
7. 세 파일을 커밋해 main에 push한다("chore(weekly): JH Weekly Report <기간>"). 거절되면 `git pull --rebase` 후 다시 push.

## 작성 규칙

- 이번 주 뉴스는 WebSearch를 `extended` 모드로 검색한다(standard는 지난 기사가 주로 나온다).
- ②③④ 목록처럼 대시보드 자체 데이터(IPO 일정·펀딩 목록)에서 온 사실은 출처 번호 없이 써도 된다. 그 밖의 사실 문장 끝에는 `[n]`, refs에 `{n, 제목, 매체, 날짜(YYYY-MM-DD), 링크}`. 출처 없는 문장은 쓰지 않는다.
- vc-news 하드 룰: 시그널≠뉴스, 교차확인(1곳뿐이면 `확실성: "단독출처"` + 추정형), 투자 추천 0건, 기간 밖 사건 금지(배경은 "(배경, YYYY-MM)"), 보도 수치 그대로.
- 문체 "~다" 체, 항목당 2~3줄 이내.

## JSON 형식

```json
{
  "id": "2026-10-26",
  "기간": { "from": "2026-10-26", "to": "2026-11-01" },
  "한눈에": ["... [1]", "..."],
  "레이더": {
    "top": [{ "제목": "...", "사실": "... [2]", "그래서우리는": "...", "확실성": "교차확인", "영향": "특정 섹터", "시간축": "6개월 내" }],
    "카테고리": {
      "자금조달": [{ "제목": "...", "사실": "... [3]", "함의": "...", "확실성": "교차확인", "날짜": "2026-10-28" }],
      "규제정책": [], "기술제품": [], "회수": [], "인력조직": []
    },
    "인사이트": ["... (5줄 이내)"]
  },
  "펀딩": { "주목": [{ "기업": "퓨리오사AI", "분야": "...", "금액": "8200억원", "단계": "시리즈D", "투자사": "...", "내용": ["... [5]", "..."] }] },
  "refs": [{ "n": 1, "제목": "...", "매체": "...", "날짜": "2026-10-28", "링크": "https://..." }]
}
```

- 카테고리가 비면 빈 배열로 둔다(화면에 "해당 없음"으로 나온다). top은 최대 5건, 카테고리당 최대 4건.
- IPO 구역만 기간이 2주다(`IPO기간`: 대상 주 월요일 ~ 발행 주 일요일). 레이더·펀딩·한눈에는 그대로 대상 주(전주)만 다루되, 한눈에서 금주 수요예측·상장 일정을 언급할 수 있다.
- `산업트래킹`·`IPO`·`IPO기간`·`펀딩.건수/공개합계억/목록`은 쓰지 않아도 된다(validate가 채운다).
